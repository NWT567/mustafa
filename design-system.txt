 4. TYPOGRAPHY & FONTS
----------------------------------------------------------------
  Fonts loaded via Google Fonts (src/styles.css line 1):
    https://fonts.googleapis.com/css2?family=DM+Serif+Display:ital@0;1
      &family=Fira+Sans:wght@300;400;500;600;700&display=swap

  FONT ROLE       FAMILY / STACK                               WEIGHTS / STYLES
  -------------  -------------------------------------------  ----------------------
  Display font   "DM Serif Display", ui-serif, Georgia, serif   Regular & Italic (ital@0;1)
  Body / Sans    "Fira Sans", ui-sans-serif, system-ui, sans    300, 400, 500, 600, 700

  Tailwind theme tokens:
    --font-display  = "DM Serif Display", ui-serif, Georgia, serif
    --font-sans     = "Fira Sans", ui-sans-serif, system-ui, sans-serif

  Application rules (src/styles.css @layer base):
    - html { font-family: var(--font-sans); }      → Fira Sans is the default
    - body { font-family: var(--font-sans);
             font-feature-settings: "ss01", "ss02";
             -webkit-font-smoothing: antialiased; }
    - h1–h6, .font-display { font-family: var(--font-display);
             letter-spacing: -0.01em; }            → DM Serif Display for headings
    - button, input, textarea, select { font-family: var(--font-sans); }

  Common text utilities used in components:
    - font-display         → switches to DM Serif Display
    - uppercase             → tracking-[0.2em] / tracking-[0.25em] for eyebrow labels
    - text-gold-gradient    → gold gradient applied via background-clip:text
